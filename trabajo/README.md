# Carpeta de trabajo del alumno

Aquí guarda **tu propio código** al usar JAVe-Ando (botón **Mi código**).

- La estructura replica `soluciones/` (por ejemplo `modulo-poo/01-clases-y-objetos/`).
- **No** sustituye a la solución oficial del profesor en `soluciones/`.
- Puedes abrir esta carpeta o una terminal desde el menú **Herramientas** del visor (Windows, Linux y macOS).
- En **Windows**, si «Terminal» no abre, usa manualmente `cd /d` hasta esta carpeta en CMD o PowerShell.

Esta carpeta puede añadirse a `.gitignore` si no quieres subir tus intentos al repositorio.
